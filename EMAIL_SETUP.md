# Подключить отправку на почту

Сам сайт готов. Для настоящих писем нужно один раз подключить приёмник. Почтовые пароли и токены GitHub в сайт не вставляются.

## Рекомендуемый вариант: свой Google Apps Script

На момент проверки 29 октября 2026 года FormSubmit возвращал ошибку 521. Чтобы не зависеть от него, в комплект добавлен собственный почтовый приёмник для Google. Он отправляет результаты только на **l1napochtipol1na@gmail.com**.

1. Сначала опубликуй сайт через GitHub Pages по `README.md` и узнай свой адрес, например `https://polina.github.io/petal/`.
2. Открой [Google Apps Script](https://script.google.com/) под своим Google-аккаунтом и создай новый проект.
3. Замени весь код в редакторе содержимым файла **google-mail.gs** из этой папки.
4. В строке `ALLOWED_ORIGIN` замени `https://YOUR-GITHUB-NAME.github.io` на свой адрес **без имени репозитория и без завершающего слеша**. Например: `https://polina.github.io`.
5. В списке функций выбери `authorizeMail`, нажми «Выполнить» и разреши своему проекту отправлять письма от твоего имени. Проекту нужна только отправка почты, чтения твоих писем он не запрашивает.
6. Нажми **Развернуть → Новое развёртывание → Веб-приложение**. Выбери **Выполнять от имени: я** и **У кого есть доступ: все / anyone**. Девушке не понадобится входить в Google. Если у рабочего аккаунта такого пункта нет, нужен личный Google-аккаунт.
7. Скопируй адрес веб-приложения, оканчивающийся на **/exec**. В файле сайта `config.js` вставь его между кавычками после `googleScriptUrl:`. Обнови этот файл в GitHub.
8. На опубликованном сайте открой **setup.html** и нажми **«Отправить контрольное письмо»**. Проверь, что письмо пришло. Затем пройди анкету целиком и проверь все ответы в письме.

Когда `googleScriptUrl` заполнен, сайт обращается только к твоему Google-проекту. FormSubmit не вызывается. Сайт показывает успех только после того, как Google подтвердит отправку. При тайм-ауте ответы остаются в браузере, а итог можно скачать или скопировать.

При изменении кода приёмника обнови развёртывание в Google: **Управление развёртываниями → Изменить → Новая версия**. Просто сохранить код в редакторе недостаточно.

Техническая справка Google: [веб-приложения](https://developers.google.com/apps-script/guides/web), [MailApp](https://developers.google.com/apps-script/reference/mail/mail-app), [встраивание ответа](https://developers.google.com/apps-script/reference/html/html-output#setXFrameOptionsMode(XFrameOptionsMode)).

## Альтернатива: FormSubmit, когда сервис доступен

Оставь `googleScriptUrl: ''`. Получатель FormSubmit уже указан. После публикации открой `setup.html`, нажми первую кнопку, подтверди **Activate Form** в письме FormSubmit, затем отправь контрольное письмо второй кнопкой.

При первом запросе FormSubmit требует активации адреса. Сделай это сам **до** отправки ссылки девушке. Без активации результаты не пересылаются. [Инструкция FormSubmit](https://formsubmit.co/documentation).

## Что получишь

Одно письмо с любимыми цветами, оттенками, настроением, композицией, размером, упаковкой, исключениями, пожеланиями и ссылкой на пример. В письме также будет готовая текстовая памятка, которую можно переслать друзьям.

Письма отправляются после финальной кнопки. Черновик и промежуточные клики остаются только в браузере участницы.
