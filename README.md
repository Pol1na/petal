# petal. — цветочный портрет

Готовый сайт на русском для GitHub Pages: семь шагов с фотографиями, сохранение черновика на устройстве, итоговая памятка, отправка на почту и скачивание результата. Работает без сборки и установки библиотек.

## Опубликовать на GitHub Pages

1. Создай репозиторий на GitHub, например `petal`.
2. Загрузи **содержимое** этой папки в корень репозитория. Рядом должны лежать `index.html`, `app.js`, `styles.css`, `config.js` и папка `assets`. Фотографии и шрифты тоже нужно загрузить. Не загружай только один HTML-файл.
3. В репозитории открой **Settings → Pages → Build and deployment**. Выбери **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажми **Save**.
4. Дождись ссылки вида `https://ИМЯ.github.io/petal/`. Можно отправлять именно её.

Относительные пути уже работают и в подпапке GitHub Pages. `.nojekyll` отключает ненужную обработку файлов.

## Подключить почту — до отправки ссылки девушке

**Важно:** при проверке 29 октября 2026 года FormSubmit не отвечал (ошибка 521). Поэтому в комплекте есть запасной собственный приёмник Google Apps Script. Рекомендуется подключить его: пошаговая инструкция в [EMAIL_SETUP.md](EMAIL_SETUP.md). Нужна одна настройка под своим Google-аккаунтом; из этого проекта доступа к твоей почте нет. Живую доставку можно проверить только после такого подключения.

Если FormSubmit снова доступен, можно использовать более короткую настройку ниже:

Получатель уже настроен: **l1napochtipol1na@gmail.com**.

1. После публикации открой `https://ИМЯ.github.io/petal/setup.html`.
2. Нажми **«Подтвердить приём ответов»**. Страница отправит только служебный тест, без личных ответов.
3. На почте найди письмо **FormSubmit** и нажми в нём **Activate Form**. Если письма нет, проверь «Спам».
4. Вернись на `setup.html` и нажми **«Отправить контрольное письмо»**. Убедись, что получено контрольное письмо.
5. Пройди анкету сам на опубликованном адресе и проверь, что пришли все ответы. После этого отправляй ссылку девушке. Можно проверить с другого браузера или в приватном окне, чтобы твой черновик не мешал.

Без подтверждения FormSubmit не сможет пересылать ответы. Доставка зависит от доступности FormSubmit и почтового сервиса; без подтверждённого ответа сервису сайт не показывает успешную отправку.

Ссылка `setup.html` служит только для проверки почты, не показывает и не хранит чужие результаты. Результаты приходят в письме: все выбранные варианты, дополнительные пожелания и готовая памятка для друзей. Сохраняется итог по нажатию кнопки «Отправить мой намёк». Промежуточные клики остаются на устройстве девушки.

## Настройка

В `config.js` можно поменять адрес получателя, вступительный текст и указать `googleScriptUrl`. Если используется Google, адрес назначения меняется также в `google-mail.gs`. После активации FormSubmit присылает непрозрачный идентификатор получателя: при желании замени им email в `recipient`, чтобы адрес не был виден в публичном исходном коде. Пароли, токены GitHub и ключи почты не нужны.

Текущий адрес виден в исходном коде сайта. Ответы не записываются в репозиторий GitHub. Они проходят через выбранный приёмник и отправляются получателю. Перед отправкой участнице показывается выбранный сервис.

Черновик хранится только в `localStorage` браузера. При недоступной отправке можно повторить попытку, скопировать или скачать итог. При ограничениях браузера на локальное хранение не стоит закрывать страницу до отправки.

## Локальный просмотр

Можно открыть `index.html` двойным кликом для просмотра. Для проверки отправки используй опубликованный HTTPS-адрес: почтовые сервисы могут отклонять запросы из `file://` и `localhost`.

Для локального сервера с Node.js:

```sh
node preview.mjs
```

Затем открой `http://localhost:4173`.

## Фотографии и шрифты

Все ресурсы находятся внутри `assets`, внешняя загрузка изображений и шрифтов не требуется. Сведения об авторах: `assets/CREDITS.md`. При отправке сайт обращается к выбранному приёмнику: Google Apps Script или FormSubmit.
